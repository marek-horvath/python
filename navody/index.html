Windows

Použite oficiálny inštalátor aktuálneho Pythonu 3 z python.org. Po inštalácii otvorte nový terminál a overte, že príkazy smerujú na rovnakú inštaláciu Pythonu.Use the official installer for the current Python 3 release from python.org. After installation, open a new terminal and verify that the commands point to the same Python installation.

python --versionpython -m pip --version

Ak používate novší Windows workflow cez Python Install Manager, cieľ je rovnaký: príkaz `python` má spustiť očakávaný Python 3 a `python -m pip` má používať rovnaký interpreter.If you use the newer Windows workflow through Python Install Manager, the goal is the same: `python` should run the expected Python 3 installation and `python -m pip` should use the same interpreter.

macOS

Najprv overte, či už máte dostupný Python 3 a pip.First check whether Python 3 and pip are already available.

python3 --versionpython3 -m pip --version

Homebrew môže byť pohodlná možnosť inštalácie, ale nie je povinný. Dôležité je vedieť, ktorý interpreter používa editor a terminál.Homebrew can be a convenient installation option, but it is not required. The important part is knowing which interpreter is used by the editor and the terminal.

Linux

Na Linuxe býva Python často súčasťou systému. Nemeňte ani nemažte systémový Python.On Linux, Python is often part of the system. Do not replace or remove the system Python.

# Ubuntu/Debianpython3 --versionpython3 -m pip --version# Fedorapython3 --versionpython3 -m pip --version

Ak balík chýba, použite balíčkovací systém distribúcie, napríklad `apt` alebo `dnf`.If a package is missing, use your distribution's package manager, such as `apt` or `dnf`.

Editor

Môžete použiť Visual Studio Code, PyCharm alebo iný editor. Podstatné je, aby ste vedeli vytvoriť súbor `.py`, spustiť Python a pracovať s terminálom.You may use Visual Studio Code, PyCharm or another editor. What matters is that you can create a `.py` file, run Python and work with the terminal.

Virtuálne prostredieVirtual Environment

Virtuálne prostredie drží knižnice projektu oddelene od systémovej inštalácie Pythonu.A virtual environment keeps project libraries separate from the system Python installation.

python -m venv .venv

Aktivácia vo Windows PowerShell:Activation in Windows PowerShell:

.venv\Scripts\Activate.ps1

Aktivácia v macOS/Linux shelli:Activation in a macOS/Linux shell:

source .venv/bin/activate

pip

Preferujte tvar `python -m pip`, aby bolo jasné, ku ktorému interpreteru knižnicu inštalujete.Prefer the `python -m pip` form so it is clear which interpreter receives the installed package.

python -m pip install requestspython -m pip listpython -m pip uninstall requests

Prvý programFirst Program

Vytvorte súbor `hello.py`:Create a file named `hello.py`:

print("Hello, world!")

Spustenie:Run it:

python hello.py

Na macOS a Linuxe môže byť príkaz podľa inštalácie `python3 hello.py`.On macOS and Linux, depending on the installation, the command may be `python3 hello.py`.

Keď niečo nefungujeWhen Something Does Not Work

  • command not found: terminál nevie nájsť Python. Skontrolujte inštaláciu a PATH.the terminal cannot find Python. Check the installation and PATH.
  • pip používa iný interpreter:pip uses a different interpreter: použite `python -m pip` namiesto samotného `pip`.use `python -m pip` instead of plain `pip`.
  • virtuálne prostredie nie je aktivované:the virtual environment is not activated: v termináli by mal byť viditeľný prefix `(.venv)`.the terminal should show the `(.venv)` prefix.
  • IDE používa nesprávny interpreter:the IDE uses the wrong interpreter: v nastaveniach projektu vyberte interpreter z priečinka `.venv`.select the interpreter from the `.venv` directory in project settings.
