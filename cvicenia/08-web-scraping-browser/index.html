Web scraping a automatizácia prehliadačaWeb Scraping and Browser Automation

PrípravaSetup

Hlavná časť cvičenia používa lokálne HTML súbory. Scraper tak nebude závisieť od cudzej stránky a môžete si pokojne skúšať selektory, parsovanie, pagination aj chybové stavy.

Starter súbory: exercises/exercise-08/
Lokálne stránky: catalog/page1.html, page2.html, page3.html
Dynamická stránka: dynamic/search.html
Výstup: product scraper + export + krátka Playwright interakcia

Starter súbory sú dostupné aj ako ZIP archív.

The main part of the exercise uses local HTML files. The scraper will not depend on someone else's website, so you can safely practice selectors, parsing, pagination and error states.

Starter files: exercises/exercise-08/
Local pages: catalog/page1.html, page2.html, page3.html
Dynamic page: dynamic/search.html
Output: product scraper + export + short Playwright interaction

Starter files are also available as a ZIP archive.

python -m pip install httpx beautifulsoup4 playwright
python -m playwright install chromium

CieleGoals

  • čítať HTML štruktúru a navrhnúť vhodné CSS selektory;
  • extrahovať dáta cez BeautifulSoup do Python objektov;
  • spracovať pagination, duplicity a chýbajúce elementy;
  • rozlíšiť statický scraping od browser automation cez Playwright.
  • read HTML structure and design suitable CSS selectors;
  • extract data with BeautifulSoup into Python objects;
  • handle pagination, duplicates and missing elements;
  • distinguish static scraping from browser automation with Playwright.

Úloha 8 — HTTPX requestTask 8 — HTTPX Request

Pridajte krátku funkciu, ktorá vie načítať HTML stránku cez HTTP. Hlavný scraper stále testujte nad lokálnymi súbormi.

Add a short function that can load an HTML page over HTTP. Keep testing the main scraper on local files.

import httpx

def fetch_page(url: str) -> str:
    headers = {"User-Agent": "python-course-scraper/1.0"}
    response = httpx.get(url, headers=headers, timeout=5.0)
    response.raise_for_status()
    return response.text

Vyskúšajte ju napríklad na https://example.com a cez BeautifulSoup vypíšte title alebo h1.
