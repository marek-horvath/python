Výsledok cvičeniaExercise Outcome

Výsledkom bude Tkinter aplikácia, ktorá pridáva úlohy tlačidlom aj klávesom Enter, odmieta prázdny vstup, prepína a odstraňuje vybranú úlohu, počíta nesplnené položky a udržiava zhodu medzi dátami a Listbox.The result will be a Tkinter application that adds tasks with a button or Enter, rejects empty input, toggles and deletes the selected task, counts incomplete items and keeps its data in sync with the Listbox.

Úloha 1 — Statické okno aplikácieTask 1 — Static Application Window

6 min

Doplňte okno s titulkom Moje úlohy. Rozložte doň nadpis, jednoriadkové vstupné pole, tlačidlo Pridať, zoznam, tlačidlá Hotové a Odstrániť a text Nesplnené: 0.

Prvky musia zostať čitateľné a oddelené aj po zväčšení okna. V tejto úlohe ešte nemusia reagovať.

Complete a window titled My tasks. Arrange a heading, a single-line input field, an Add button, a list, Done and Delete buttons, and the text Incomplete: 0.

The widgets must remain readable and separated when the window is enlarged. They do not need to respond yet.

Moje úlohy
[________________________] [Pridať]

|                              |
|                              |

[Hotové]             [Odstrániť]
Nesplnené: 0
My tasks
[________________________] [Add]

|                              |
|                              |

[Done]                    [Delete]
Incomplete: 0

Úloha 2 — Pridanie riadka kliknutímTask 2 — Add a Row by Clicking

8 min

Po kliknutí na Pridať vložte aktuálny text zo vstupného poľa ako nový posledný riadok zoznamu.

Overte postupným pridaním troch rôznych úloh. Nová položka nesmie nahradiť predchádzajúcu a jedno kliknutie nesmie vytvoriť viac než jeden riadok.

After clicking Add, insert the current input value as the new last row in the list.

Verify the behaviour by adding three different tasks. A new item must not replace a previous one, and one click must not create more than one row.

Vstup: Poslať zadanie
Klik: Pridať

Zoznam:
Poslať zadanie
Input: Submit assignment
Click: Add

List:
Submit assignment

Úloha 3 — Platný vstup a vyčistenie poľaTask 3 — Valid Input and Field Cleanup

7 min

Vstup zložený iba z prázdneho reťazca alebo medzier nesmie vytvoriť úlohu. Medzery na začiatku a konci platného textu sa nemajú zobraziť v zozname.

Po úspešnom pridaní vyčistite vstupné pole. Po odmietnutí prázdneho vstupu musí existujúci zoznam zostať bez zmeny.

An empty string or whitespace-only input must not create a task. Leading and trailing whitespace from valid text must not appear in the list.

Clear the input field after a successful add. Rejecting empty input must leave the existing list unchanged.

"   "                  → bez novej položky
"  Poslať zadanie  " → Poslať zadanie

Vstup po pridaní: prázdny
"   "                    → no new item
"  Submit assignment  " → Submit assignment

Input after adding: empty

Úloha 4 — Rovnaká akcia cez EnterTask 4 — The Same Action with Enter

8 min

Stlačenie Enter vo vstupnom poli musí mať rovnaký výsledok ako kliknutie na Pridať, vrátane validácie a vyčistenia poľa.

Pravidlá pridávania nesmú existovať v dvoch odlišných implementáciách. Overte striedavo tlačidlo, Enter, prázdny vstup a text s okrajovými medzerami.

Pressing Enter in the input field must have the same result as clicking Add, including validation and field cleanup.

The add rules must not exist as two separate implementations. Test the button, Enter, empty input and text with surrounding whitespace in turn.

Klik na Pridať: 1 nová úloha
Enter:           1 nová úloha
Prázdny vstup:  0 nových úloh
Click Add:  1 new task
Enter:      1 new task
Empty input: 0 new tasks

Úloha 5 — Dáta ako zdroj pravdyTask 5 — Data as the Source of Truth

12 min

Prestaňte považovať text v zozname za jediný stav aplikácie. Každú úlohu uchovávajte v samostatnom dátovom zozname spolu s textom a informáciou, či je hotová.

Vytvorte jedno miesto, ktoré vymaže starý obsah zoznamu a z aktuálnych dát znova zobrazí všetky riadky. Nesplnenú úlohu zobrazte so značkou [ ] a hotovú so značkou [x].

Po tejto zmene musí pridávanie navonok fungovať rovnako ako predtým.

Stop treating the text displayed in the list as the application's only state. Store each task in a separate data list together with its text and completion state.

Create one place that removes the old list contents and renders every row again from current data. Display an incomplete task with [ ] and a completed task with [x].

After this change, adding a task must look the same to the user as before.

Dáta: 2 záznamy

Zoznam:
[ ] Poslať zadanie
[x] Prejsť si callbacky
Data: 2 records

List:
[ ] Submit assignment
[x] Review callbacks

Úloha 6 — Bezpečná práca s výberomTask 6 — Safe Selection Handling

8 min

Zistite, ktorý riadok používateľ označil. Kliknutie na Hotové alebo Odstrániť bez označeného riadka nesmie skončiť tracebackom ani zmeniť dáta.

Pri označení druhého riadka musíte ďalej pracovať s druhou úlohou, aj keď majú dve úlohy rovnaký text.

Determine which row the user selected. Clicking Done or Delete without a selected row must not produce a traceback or change the data.

When the second row is selected, further operations must target the second task even if two tasks have identical text.

Žiadny výber + Hotové   → bez zmeny
Žiadny výber + Odstrániť → bez zmeny
Druhý riadok vybraný      → pracuje sa s indexom 1
No selection + Done   → no change
No selection + Delete → no change
Second row selected   → operate on index 1

Úloha 7 — Prepínanie dokončeniaTask 7 — Toggle Completion

10 min

Tlačidlo Hotové musí prepnúť boolean stav vybratej úlohy a obnoviť celý zoznam z dát.

Po obnove ponechajte rovnaký riadok označený. Dve po sebe idúce kliknutia na Hotové bez opätovného výberu preto musia vrátiť úlohu do pôvodného stavu.

The Done button must toggle the selected task's boolean state and refresh the whole list from data.

Keep the same row selected after the refresh. Two consecutive Done clicks without selecting the row again must therefore return the task to its original state.

Začiatok: [ ] Poslať zadanie
1. klik:  [x] Poslať zadanie
2. klik:  [ ] Poslať zadanie
Start:     [ ] Submit assignment
1st click: [x] Submit assignment
2nd click: [ ] Submit assignment

Úloha 8 — Odstránenie vybratej úlohyTask 8 — Delete the Selected Task

8 min

Tlačidlo Odstrániť musí odstrániť vybratú úlohu z dát a následne obnoviť zobrazenie.

Overte odstránenie prvého, posledného aj jediného riadka. Po odstránení poslednej úlohy musí zostať prázdny zoznam a aplikácia musí ďalej prijímať nové úlohy.

The Delete button must remove the selected task from data and then refresh the view.

Test deleting the first, last and only row. After deleting the final task, the list must remain empty and the application must still accept new tasks.

Pred odstránením:
[ ] Poslať zadanie
[x] Prejsť si callbacky

Po odstránení prvého riadka:
[x] Prejsť si callbacky
Before deletion:
[ ] Submit assignment
[x] Review callbacks

After deleting the first row:
[x] Review callbacks

Úloha 9 — Odvodené počítadloTask 9 — Derived Counter

8 min

Text pod zoznamom musí po každej zmene ukazovať počet úloh, ktoré ešte nie sú hotové. Počet vždy odvoďte z aktuálnych dát; nesmie sa rozísť so zoznamom ani po opakovanom prepínaní a odstraňovaní.

Overte nasledujúcu sekvenciu bez reštartovania aplikácie.

The text below the list must show the number of tasks that are not yet complete after every change. Always derive the value from current data; it must not diverge from the list after repeated toggles or deletions.

Verify the following sequence without restarting the application.

pridať A       → Nesplnené: 1
pridať B       → Nesplnené: 2
označiť A      → Nesplnené: 1
odstrániť B    → Nesplnené: 0
prepnúť A späť → Nesplnené: 1
add A         → Incomplete: 1
add B         → Incomplete: 2
complete A    → Incomplete: 1
delete B      → Incomplete: 0
toggle A back → Incomplete: 1

Úloha 10 — Dokončenie pracovného tokuTask 10 — Complete the Workflow

15 min

Pridajte tlačidlo Odstrániť hotové. Jednou akciou odstráni z dát všetky dokončené úlohy, ponechá nesplnené úlohy v pôvodnom poradí a obnoví zoznam aj počítadlo.

Ak nie je hotová žiadna úloha, kliknutie nesmie zmeniť zoznam. Po každej operácii musí aplikácia zostať použiteľná: možno pridať ďalšiu úlohu, výber bez položky nespôsobí chybu a počítadlo zostane správne.

Na záver vykonajte celý akceptačný scenár bez reštartu aplikácie.

Add a Delete completed button. In one action, it removes all completed tasks from data, preserves the original order of incomplete tasks, and refreshes both the list and the counter.

If no task is complete, clicking the button must not change the list. The application must remain usable after every operation: another task can be added, an empty selection causes no error, and the counter remains correct.

Finally, complete the entire acceptance scenario without restarting the application.

1. Pridajte A, B, C.
2. Označte A a C ako hotové.
3. Kliknite Odstrániť hotové.
4. Zostáva iba [ ] B a Nesplnené: 1.
5. Pridajte D klávesom Enter.
6. Zostávajú [ ] B, [ ] D a Nesplnené: 2.
1. Add A, B and C.
2. Mark A and C as done.
3. Click Delete completed.
4. Only [ ] B remains and Incomplete: 1.
5. Add D with Enter.
6. [ ] B and [ ] D remain and Incomplete: 2.

Akceptačný checklistAcceptance Checklist

  • tlačidlo aj Enter pridávajú presne jednu platnú úlohu;
  • prázdny vstup a vstup iba z medzier sa ignorujú;
  • dáta, riadky v zozname a počítadlo zostávajú zhodné;
  • akcie bez výberu nespôsobia chybu ani zmenu dát;
  • dokončenie sa dá opakovane prepínať bez nového výberu;
  • odstránenie funguje pre prvý, posledný aj jediný riadok;
  • hromadné odstránenie nemení poradie zostávajúcich úloh;
  • po ľubovoľnej sekvencii akcií možno pridať ďalšiu úlohu.
  • the button and Enter each add exactly one valid task;
  • empty and whitespace-only input is ignored;
  • data, displayed rows and the counter remain consistent;
  • actions without a selection cause no error or data change;
  • completion can be toggled repeatedly without selecting again;
  • deletion works for the first, last and only row;
  • bulk deletion preserves the order of remaining tasks;
  • a new task can be added after any sequence of actions.
