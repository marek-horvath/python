GUI a event-driven programovanieGUI and Event-Driven Programming

PrípravaSetup

Python 3.x s modulom tkinter
Odporúčané: IDE, ktoré vie spustiť GUI aplikáciu
Externé knižnice: nie
Pracovné súbory: gui_form.py, converter.py, text_tools.py, file_dashboard.py

Ak import tkinter zlyhá, doplňte Tkinter podľa operačného systému ešte pred riešením úloh.

Python 3.x with the tkinter module
Recommended: an IDE that can run GUI applications
External libraries: no
Working files: gui_form.py, converter.py, text_tools.py, file_dashboard.py

If import tkinter fails, install Tkinter for your operating system before working on the tasks.

CieleGoals

  • navrhnúť GUI aplikáciu okolo event loopu, callbackov a stavu;
  • použiť ttk widgety, layout a vstupnú validáciu;
  • oddeliť UI callbacky od aplikačnej logiky;
  • pracovať s dialógmi, klávesnicou, Canvas a after().
  • design a GUI application around an event loop, callbacks and state;
  • use ttk widgets, layout and input validation;
  • separate UI callbacks from application logic;
  • work with dialogs, keyboard events, Canvas and after().

Úloha 1 — Registračný formulár s validáciouTask 1 — Registration Form with Validation

Vytvorte aplikáciu gui_form.py s formulárom používateľa.

Formulár má obsahovať:

  • pole Meno;
  • pole Email;
  • pole Vek;
  • tlačidlo Odoslať;
  • tlačidlo Reset;
  • label pre výsledok alebo chybovú správu.

Požadovaná validácia:

  • meno nesmie byť prázdne;
  • email musí obsahovať @ a bodku za @;
  • vek musí byť celé číslo od 15 do 99;
  • pri chybe sa nezobrazí úspešná správa.
Vstup:
Meno: Anna Horváth
Email: anna@example.com
Vek: 21

Výsledok v GUI:
Používateľ Anna Horváth bol uložený.

Pomôcka: Callback tlačidla má iba načítať hodnoty, validovať ich a aktualizovať UI. Nepíšte command=submit().

Create an application gui_form.py with a user form.

The form should contain:

  • a Name field;
  • an Email field;
  • an Age field;
  • a Submit button;
  • a Reset button;
  • a label for the result or error message.

Required validation:

  • name must not be empty;
  • email must contain @ and a dot after @;
  • age must be an integer from 15 to 99;
  • when validation fails, do not show the success message.
Input:
Name: Anna Horváth
Email: anna@example.com
Age: 21

Result in GUI:

Hint: The button callback should only read values, validate them and update the UI. Do not write command=submit().

Vytvorte GUI konvertor, ktorý používa Entry, ttk.Combobox, Button a výstupný label.

Podporujte minimálne tieto prevody:

  • kilometre → metre;
  • Celsius → Fahrenheit;

Požiadavky:

Create a GUI converter that uses Entry, ttk.Combobox, Button and an output label.

Requirements:

  • conversion type is selected with a combobox;
  • round the result to two decimal places;
  • for invalid input, show an error in the GUI, not a traceback in the terminal;

Úloha 4 — Refactoring zlého callbackuTask 4 — Refactoring a Bad Callback

Nasledujúci callback mieša čítanie widgetov, validáciu, výpočet aj formátovanie výstupu. Prepíšte ho tak, aby sa dal testovať mimo GUI.

The following callback mixes widget reads, validation, calculation and output formatting. Rewrite it so it can be tested outside the GUI.

def on_filter_click():
    text = search_entry.get().strip().lower()
    min_credits_text = credits_entry.get().strip()
    if min_credits_text == "":
        min_credits = 0
    else:
        min_credits = int(min_credits_text)

    output.delete(0, tk.END)
    count = 0
    for course in courses:
        if text in course["title"].lower() or text in course["code"].lower():
            if course["credits"] >= min_credits:
                output.insert(tk.END, course["code"] + " " + course["title"])
                count += 1

    status_label.config(text=f"Found: {count}")

Požiadavky na refactoring:

  • vytvorte dátový model alebo aspoň jasnú štruktúru pre kurz;
  • vytvorte čistú funkciu na filtrovanie;
  • validáciu min_credits riešte mimo samotného výpisu do UI;
  • callback nech iba koordinuje čítanie vstupu, volanie funkcií a aktualizáciu widgetov;
  • ošetrite nečíselný vstup pre kredity.

Refactoring requirements:

  • create a data model or at least a clear structure for a course;
  • create a pure function for filtering;
  • handle validation of min_credits outside the actual UI output;
  • let the callback only coordinate input reads, function calls and widget updates;
  • handle non-numeric input for credits.
def filter_courses(
    courses: list[Course],
    query: str = "",
    teacher: str | None = None,
    min_credits: int = 0,
) -> list[Course]:
    ...

Na konci porovnajte, ktorá časť kódu je teraz testovateľná bez spustenia okna.

At the end, compare which part of the code is now testable without opening a window.
