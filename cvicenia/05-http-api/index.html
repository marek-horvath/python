CieleGoals

  • čítať API dokumentáciu a preložiť ju na request cez httpx;
  • pracovať s query parameters, headers, status codes a JSON;
  • oddeliť request, parsing, model a výpis;
  • riešiť timeout, HTTP chyby, network chyby a neplatný vstup.
  • read API documentation and translate it into requests with httpx;
  • work with query parameters, headers, status codes and JSON;
  • separate request code, parsing, model and output;
  • handle timeouts, HTTP errors, network errors and invalid input.

ÚlohyTasks

Úloha 1 — API probeTask 1 — API Probe

Vytvorte skript api_probe.py, ktorý zavolá Open-Meteo forecast endpoint pre pevne zadané súradnice Košíc.

Create a script api_probe.py that calls the Open-Meteo forecast endpoint for fixed Košice coordinates.

import httpx

url = "https://api.open-meteo.com/v1/forecast"
params = {
    "latitude": 48.7164,
    "longitude": 21.2611,
    "current": "temperature_2m,wind_speed_10m",
}

response = httpx.get(url, params=params, timeout=5.0)
response.raise_for_status()

Vypíšte:

  • finálnu URL, ktorú HTTPX zostavil;
  • status code;
  • content type;
  • top-level JSON kľúče;
  • hodnotu current.temperature_2m, ak existuje.

Print:

  • the final URL built by HTTPX;
  • status code;
  • content type;
  • top-level JSON keys;
  • the value of current.temperature_2m, if present.
Status: 200
Content-Type: application/json
Keys: latitude, longitude, generationtime_ms, utc_offset_seconds, timezone, current_units, current
Temperature: 18.7 °C

Úloha 2 — Query parameters bez ručného URL stringuTask 2 — Query Parameters Without Manual URL Strings

Rozšírte request tak, aby sa všetky meniteľné hodnoty posielali cez params.

Požadované parametre:

  • latitude;
  • longitude;
  • current s teplotou, vetrom a relatívnou vlhkosťou;
  • timezone nastavený na Europe/Bratislava.

Extend the request so that all variable values are passed through params.

Required parameters:

  • latitude;
  • longitude;
  • current with temperature, wind and relative humidity;
  • timezone set to Europe/Bratislava.
params = {
    "latitude": latitude,
    "longitude": longitude,
    "current": "temperature_2m,wind_speed_10m,relative_humidity_2m",
    "timezone": "Europe/Bratislava",
}

Overte request pre Košice, Bratislavu a Prahu. Súradnice uložte do dictionary, nie do troch samostatných premenných.

Check the request for Košice, Bratislava and Prague. Store coordinates in a dictionary, not in three separate variables.

Košice      48.7164  21.2611
Bratislava  48.1486  17.1077
Prague      50.0755  14.4378

Nevypisujte celú JSON odpoveď. Vytvorte funkciu, ktorá z odpovede vyberie iba údaje potrebné pre textový report.

Report má obsahovať:

  • mesto;
  • čas merania;
  • teplotu;
  • rýchlosť vetra;
  • relatívnu vlhkosť;
  • jednotky načítané z current_units.
Košice
Čas: 2026-09-21T13:30
Teplota: 18.7 °C
Vietor: 9.4 km/h
Vlhkosť: 62 %

Ak odpoveď neobsahuje očakávaný kľúč, vyhoďte vlastnú zrozumiteľnú chybu, napríklad ValueError.

Do not print the whole JSON response. Create a function that extracts only the data needed for a text report.

The report should include:

  • city;
  • measurement time;
  • temperature;
  • wind speed;
  • relative humidity;
  • units loaded from current_units.
Košice
Time: 2026-09-21T13:30
Temperature: 18.7 °C

Humidity: 62 %

If the response does not contain an expected key, raise your own readable error, for example ValueError.

Úloha 4 — Dataclass model odpovedeTask 4 — Dataclass Response Model

Preložte vybrané dáta z API do Python objektu.

Translate selected API data into a Python object.

from dataclasses import dataclass


@dataclass
class Weather:
    city: str
    time: str
    temperature: float
    temperature_unit: str
    wind_speed: float
    wind_unit: str
    humidity: int
    humidity_unit: str

Implementujte funkcie:

  • fetch_weather(latitude: float, longitude: float) -> dict;
  • parse_weather(city: str, data: dict) -> Weather;
  • format_weather(weather: Weather) -> str.

HTTP request, parsing a výpis nemajú byť v jednej päťdesiatriadkovej funkcii.

Implement these functions:

  • fetch_weather(latitude: float, longitude: float) -> dict;
  • parse_weather(city: str, data: dict) -> Weather;
  • format_weather(weather: Weather) -> str.

The HTTP request, parsing and output should not live in one fifty-line function.

Úloha 5 — Geocoding searchTask 5 — Geocoding Search

Namiesto pevne zadaných súradníc pridajte vyhľadanie mesta cez Open-Meteo Geocoding API.

Instead of fixed coordinates, add city lookup through the Open-Meteo Geocoding API.

url = "https://geocoding-api.open-meteo.com/v1/search"
params = {
    "name": "Kosice",
    "count": 5,
    "language": "en",
    "format": "json",
}

Funkcia search_locations(query: str) -> list[Location] má vrátiť zoznam kandidátov.

Každý kandidát má obsahovať:

  • názov;
  • krajinu;
  • latitude;
  • longitude;
  • timezone, ak je v odpovedi dostupný.
1. Košice, Slovakia        48.7164  21.2611
2. Košice-okolie, Slovakia 48.7000  21.3333

Ak API nevráti žiadne výsledky, program má vypísať stručnú správu a neskončiť náhodným IndexError.

The function search_locations(query: str) -> list[Location] should return a list of candidates.

Each candidate should contain:

  • name;
  • country;
  • latitude;
  • longitude;
  • timezone, if available in the response.
1. Košice, Slovakia        48.7164  21.2611
2. Košice-okolie, Slovakia 48.7000  21.3333

If the API returns no results, the program should print a short message and not end with an accidental IndexError.

Úloha 6 — Error handling a timeoutTask 6 — Error Handling and Timeout

Všetky requesty musia mať timeout a zrozumiteľné spracovanie chýb.

All requests must have a timeout and readable error handling.

try:
    response = httpx.get(url, params=params, timeout=5.0)
    response.raise_for_status()
except httpx.TimeoutException:
    ...
except httpx.HTTPStatusError:
    ...
except httpx.NetworkError:
    ...

Požiadavky:

  • timeout nastavte explicitne;
  • pri 4xx/5xx zobrazte status code;
  • pri network chybe zobrazte, že služba alebo sieť nie je dostupná;
  • nepoužívajte except: pass;
  • do README alebo komentára dopíšte jednu vetu, prečo timeout patrí do sieťového requestu.
Chyba: Open-Meteo neodpovedalo do 5.0 s.
Chyba: API vrátilo status 400.
Chyba: sieťové spojenie zlyhalo.

Requirements:

  • set the timeout explicitly;
  • for 4xx/5xx responses, show the status code;
  • for a network error, show that the service or network is unavailable;
  • do not use except: pass;
  • add one sentence to README or a comment explaining why network requests need a timeout.
Error: Open-Meteo did not respond within 5.0 s.
Error: API returned status 400.
Error: network connection failed.

Úloha 7 — Headers a základná diagnostikaTask 7 — Headers and Basic Diagnostics

Doplňte jednoduchú diagnostiku requestu a odpovede.

Program má voliteľne pri argumente --verbose vypísať:

  • HTTP method;
  • URL bez ručného skladania query stringu;
  • status code;
  • content type;
  • dĺžku response body;
  • čas requestu, ak ho viete rozumne zmerať.

Add simple diagnostics for the request and response.

When the optional argument --verbose is used, the program should print:

  • HTTP method;
  • URL without manually building the query string;
  • status code;
  • content type;
  • response body length;
  • request time, if you can measure it reasonably.
headers = {
    "User-Agent": "python-course-weather-cli/1.0",
}
GET https://api.open-meteo.com/v1/forecast?latitude=48.7164&...
Status: 200
Content-Type: application/json
Body size: 812 bytes

Diagnostika má pomôcť pri debugovaní, ale bežný výstup programu má ostať krátky.

Diagnostics should help debugging, but the normal program output should remain short.

Úloha 8 — Viac výsledkov a výber lokalityTask 8 — Multiple Results and Location Selection

Geocoding API môže vrátiť viac lokalít s podobným názvom. Program nemá slepo zobrať prvý záznam bez kontroly.

Implementujte jednu z možností:

  • argument --country, ktorý obmedzí výsledky podľa krajiny;
  • výpis kandidátov a výber cez číslo;
  • automatický výber iba vtedy, keď je výsledok jednoznačný.

The Geocoding API may return multiple locations with similar names. The program should not blindly take the first record without checking it.

Implement one of these options:

  • a --country argument that restricts results by country;
  • print candidates and let the user select by number;
  • select automatically only when the result is unambiguous.
python weather_cli.py "Kosice" --country Slovakia
python weather_cli.py "Paris" --count 5
Nájdené lokality:
1. Paris, France
2. Paris, United States
3. Paris, Canada

Vyberte číslo lokality: 1

Neplatný výber ošetrite zrozumiteľnou správou.

Found locations:
1. Paris, France
2. Paris, United States
3. Paris, Canada

Select location number: 1

Handle invalid selections with a readable message.

Úloha 9 — API compositionTask 9 — API Composition

Spojte geocoding endpoint a forecast endpoint do jedného workflow.

Funkcia get_weather_for_city(city: str) -> Weather má:

  • vyhľadať lokalitu;
  • získať súradnice;
  • zavolať forecast endpoint;
  • spracovať JSON;
  • vrátiť Weather objekt;
  • pri chybe vyhodiť alebo vrátiť zmysluplne popísaný problém.
Košice, Slovakia
Teplota: 18.7 °C
Vietor: 9.4 km/h
Vlhkosť: 62 %
Zdroj: Open-Meteo

Táto úloha má otestovať, či máte request, parsing a model rozdelené tak, aby sa dali kombinovať bez kopírovania kódu.

Combine the geocoding endpoint and forecast endpoint into one workflow.

The function get_weather_for_city(city: str) -> Weather should:

  • search for a location;
  • obtain coordinates;
  • call the forecast endpoint;
  • process JSON;
  • return a Weather object;
  • raise or return a meaningfully described problem on error.
Košice, Slovakia
Temperature: 18.7 °C
Wind: 9.4 km/h
Humidity: 62 %
Source: Open-Meteo

This task checks whether request code, parsing and the model are separated well enough to combine them without copying code.

Úloha 10 — Kompletný CLI API clientTask 10 — Complete CLI API Client

Dokončite weather_cli.py ako použiteľný command-line nástroj.

Finish weather_cli.py as a usable command-line tool.

python weather_cli.py Kosice
python weather_cli.py Kosice --country Slovakia
python weather_cli.py Kosice Bratislava Praha --verbose
python weather_cli.py --lat 48.7164 --lon 21.2611 --name Košice

Minimálne požiadavky:

  • argumenty cez argparse;
  • podpora mesta aj priamych súradníc;
  • viac miest v jednom spustení;
  • requesty cez httpx s timeoutom;
  • geocoding + forecast workflow;
  • dataclass modely pre lokalitu a počasie;
  • čitateľný textový report;
  • zrozumiteľné chybové správy;
  • bez vypisovania celého JSON na používateľa.
Košice, Slovakia     18.7 °C   vietor  9.4 km/h   vlhkosť 62 %
Bratislava, Slovakia 20.1 °C   vietor 12.0 km/h   vlhkosť 58 %
Praha, Czechia       17.9 °C   vietor  8.8 km/h   vlhkosť 65 %

Async nepoužívajte. Dôležitejšie je správne rozdelenie kódu, chybové stavy a práca s API odpoveďou.

Minimum requirements:

  • arguments through argparse;
  • support both city names and direct coordinates;
  • multiple cities in one run;
  • requests through httpx with a timeout;
  • geocoding + forecast workflow;
  • dataclass models for location and weather;
  • readable text report;
  • clear error messages;
  • do not print the whole JSON response to the user.
Košice, Slovakia     18.7 °C   wind  9.4 km/h   humidity 62 %
Bratislava, Slovakia 20.1 °C   wind 12.0 km/h   humidity 58 %
Prague, Czechia      17.9 °C   wind  8.8 km/h   humidity 65 %

Do not use async. Correct code separation, error states and working with the API response are more important here.
