PrípravaSetup

Budete pracovať s datasetom výsledkov programátorských úloh. Cieľom je prejsť celý malý data-science workflow: načítanie dát, kontrola kvality, čistenie, transformácie, agregácie, spájanie tabuliek a vizualizácia.

Starter súbory: exercises/exercise-07/
Datasety: programming_results.csv, students.csv
Výstupy: krátky notebook alebo Python skript + 3 grafy + stručné zistenia

Starter súbory sú dostupné aj ako ZIP archív.

You will work with a dataset of programming assignment results. The goal is to go through a small data-science workflow: loading data, checking quality, cleaning, transformations, aggregations, table joins and visualization.

Starter files: exercises/exercise-07/
Datasets: programming_results.csv, students.csv
Outputs: short notebook or Python script + 3 charts + concise findings

Starter files are also available as a ZIP archive.

python -m pip install numpy pandas matplotlib

CieleGoals

  • použiť pandas na praktickú prácu s CSV datasetom;
  • robiť čistiace rozhodnutia podľa pravidiel, nie naslepo;
  • vytvoriť odvodené stĺpce, agregácie, merge a základné grafy;
  • oddeliť technický výpočet od stručnej interpretácie výsledkov.
  • use pandas for practical work with a CSV dataset;
  • make cleaning decisions based on explicit rules, not guesswork;
  • create derived columns, aggregations, merge operations and basic charts;
  • separate technical computation from concise interpretation of results.

Úloha 4 — Odvodené stĺpceTask 4 — Derived Columns

Do clean_df pridajte stĺpce, ktoré budú užitočné pri analýze.

Vytvorte:

  • passed: points >= 50;
  • points_per_attempt: body delené počtom pokusov;
  • duration_category: short, medium, long podľa trvania;
  • submitted_weekday: deň v týždni odvodený zo submitted_at.

Add columns to clean_df that will be useful for analysis.

Create:

  • passed: points >= 50;
  • points_per_attempt: points divided by attempt count;
  • duration_category: short, medium, long based on duration;
  • submitted_weekday: weekday derived from submitted_at.
import numpy as np

clean_df["passed"] = clean_df["points"] >= 50
clean_df["duration_category"] = np.select(
    [
        clean_df["duration_minutes"] < 60,
        clean_df["duration_minutes"] <= 90,
    ],
    ["short", "medium"],
    default="long",
)

Overte, že nové stĺpce majú očakávané typy a nevznikli v nich chýbajúce hodnoty.

Verify that the new columns have expected types and contain no missing values.

Úloha 6 — GroupBy agregácieTask 6 — GroupBy Aggregations

Pomocou groupby vytvorte tabuľky, ktoré odpovedajú na konkrétne otázky.

Zistite:

  • priemerné, minimálne a maximálne body podľa predmetu;
  • počet odovzdaní podľa predmetu a tasku;
  • úspešnosť podľa predmetu v percentách;
  • priemerný počet pokusov podľa tasku;
  • ktorý predmet má najvyšší priemerný výsledok.

Use groupby to create tables that answer concrete questions.

Find:

  • average, minimum and maximum points by course;
  • number of submissions by course and task;
  • pass rate by course in percent;
  • average number of attempts by task;
  • which course has the highest average result.
course_summary = clean_df.groupby("course").agg(
    submissions=("student_id", "count"),
    average_points=("points", "mean"),
    pass_rate=("passed", "mean"),
)

course_summary["pass_rate"] = course_summary["pass_rate"] * 100

Úloha 9 — VizualizácieTask 9 — Visualizations

Vytvorte tri grafy, ktoré súvisia s predchádzajúcimi otázkami.

Minimálne grafy:

Každý graf musí mať názov, označené osi a rozumnú veľkosť. Grafy uložte do súborov.
