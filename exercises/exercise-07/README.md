# Cvičenie 07 — Data Science v Pythone

Starter dataset a základný skript k pandas/NumPy/Matplotlib cvičeniu.

Súbory:

- `programming_results.csv` — hlavný dataset s výsledkami programátorských úloh;
- `students.csv` — doplnkový dataset so študijným programom a ročníkom;
- `analysis_starter.py` — štartovací súbor na riešenie 10 úloh zo stránky cvičenia.

Odporúčaná inštalácia:

```bash
python -m pip install numpy pandas matplotlib
```

Výstupom má byť notebook alebo spustiteľný skript s čistením dát, agregáciami, grafmi a krátkou interpretáciou výsledkov.
