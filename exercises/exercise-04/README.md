# Cvičenie 04 - Testovanie, debugging a kvalita kódu

Inštalácia nástrojov:

```bash
python -m pip install pytest ruff
```

Spustenie testov:

```bash
python -m pytest
```

Kontrola štýlu:

```bash
ruff check .
ruff format .
```

V projekte sú úmyselné chyby a niekoľko lint problémov. Opravujte ich postupne podľa zadania.
