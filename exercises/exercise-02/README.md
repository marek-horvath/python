# Cvičenie 02 - Skriptovanie a automatizácia

Pracujte postupne podľa stránky cvičenia.

Odporúčaný postup:

```bash
python organizer.py sample_downloads --config categories.json --dry-run
python organizer.py sample_downloads --config categories.json
```

Súbory v `sample_downloads/` sú iba testovacie dáta. Môžete ich kopírovať alebo obnoviť zo ZIP archívu.
