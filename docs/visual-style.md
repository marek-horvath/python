# Vizuálny štýl

## Charakter

Web a slajdy majú pôsobiť ako jednoduché univerzitné materiály: dobrá typografia, jasná štruktúra, čitateľný kód a minimum dekorácie.

Referenčný pocit: univerzitné poznámky, technická dokumentácia, minimalistický osobný web a dobre zalomená učebnica. Nie SaaS landing page.

## Čomu sa vyhýbať

- veľký hero section;
- marketingové CTA;
- štatistické boxy;
- pill badges;
- gradientové nadpisy;
- neon purple/blue gradienty;
- glow efekty;
- glassmorphism;
- dekoratívne blob tvary;
- veľké rounded cards;
- ikona pri každej položke;
- hover gimmicky;
- fake dashboard vzhľad.

## Paleta

Základ:

- pozadie: `#ffffff`;
- papier/slajd: `#ffffff`;
- jemná plocha: `#f5f8fc`;
- text: `#111827`;
- muted text: `#556171`;
- linky a deliace čiary: `#d7e0eb`;
- accent: `#1d4f91`;
- code background: `#0f172a`.

Accent farbu používaj striedmo: odkazy, čísla, jemné deliace prvky, zvýraznené riadky kódu.

## Typografia

- Web používa systémové sans-serif fonty.
- Kód používa `Consolas`.
- Nepoužívaj záporné letter spacing.
- Nepoužívaj font-size odvodený od šírky viewportu.
- Na stránkach drž text v rozumnej šírke.
- Na slajdoch používaj stabilné rozmery 1280×720 a škáluj celý slajd, nie jednotlivé fonty.

## Layout

- Navigácia webu je iba `Úvod | Prednášky | Cvičenia | Projekt | Návody | Cheatsheet`.
- Zoznam prednášok je typografický zoznam, nie grid kariet.
- Stránka konkrétnej prednášky je samotná prezentácia.
- Viewer má veľký 16:9 slajd, jemný progress, späť na zoznam, fullscreen a ovládanie klávesnicou.
